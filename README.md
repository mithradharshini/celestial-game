# CELESTIAL ✦

> *"Find what belongs together."*

**CELESTIAL** is an elegant, atmospheric memory-matching browser game set in a deep night sky across 5 celestial progression stages.

---

## ✦ Features

- **5 Celestial Stages**:
  - **Stage 1: Crescent 🌒** (4×3 grid, 6 pairs) — Master the basics.
  - **Stage 2: Half Moon 🌓** (4×4 grid, 8 pairs) — Starlight shimmer every 3rd match; smooth moon phase transition.
  - **Stage 3: Gibbous 🌔** (5×4 grid, 10 pairs) — Introduces the 60s countdown timer.
  - **Stage 4: Full Moon 🌕** (6×4 grid, 12 pairs, 75s timer) — **Eclipse Mechanic**: flipping a `🌑` Eclipse tile dims all other tiles for 2s.
  - **Stage 5: Constellation ⭐** (6×5 grid, 15 pairs, 90s timer) — 15 distinct symbols, Eclipse dimming, and an interactive **Choreographed Constellation Finale**.
- **Visuals & Polish**:
  - Canvas-driven twinkling and drifting starfield.
  - Dynamically rendered lunar phases that evolve as you progress.
  - CSS 3D perspective tile flips with custom constellation vector backs.
  - Responsive orientation transposition: automatically flips grid columns and rows on portrait screens so tiles stay large and tap-friendly on mobile devices.
  - Built with accessibility and `prefers-reduced-motion` in mind.

---

## ✦ Tech Stack

- Plain **HTML5**, **CSS3**, and **vanilla JavaScript**
- Zero dependencies, no build steps, no frameworks
- Runs instantly in any modern web browser

---

## ✦ How to Play

1. Tap a tile to flip it.
2. Find two identical celestial symbols to form a match.
3. Match all pairs before dawn to complete the sky!
